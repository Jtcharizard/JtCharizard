## Sobre mim

Sou **Juan**, estudante de Desenvolvimento Web e desenvolvedor em formação. Gosto de pegar ideias — inclusive as que parecem aleatórias demais — e transformá-las em aplicativos, jogos e ferramentas que realmente funcionam.

Hoje trabalho principalmente com **Flutter, Java, JavaScript e desenvolvimento web**, explorando interface, lógica, persistência de dados e automação de builds.

Também sou responsável pelo desenvolvimento técnico da **JT Sites**, iniciativa voltada à criação de sites profissionais, modernos e responsivos para pequenos negócios.
